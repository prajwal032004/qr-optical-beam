Optical Beam Protocol Specification (QRF v1)
Zero Internet Required

AirQR uses pure light photons to achieve air-gapped, unidirectional and bidirectional data transfers between mobile devices and desktop computers without Bluetooth, Wi-Fi, cables, or servers.

High-Speed Pre-Caching
Frames are pre-rendered into memory bitmaps ahead of time to eliminate frame-drop stuttering and support streaming up to 16 FPS.
Selective Repeat QR Reverse Feedback
If optical interference causes packets to drop, the receiver displays a reverse request QR containing missing indices. The sender reads this to transmit ONLY missing frames.
SHA-256 Bit-Level Integrity
Every payload is cryptographically authenticated with SHA-256 before disk reconstruction to prevent corruption or incomplete writes.
